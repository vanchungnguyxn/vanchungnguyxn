## About

Cyber security student from **Viet Nam** focused on defensive tooling, integrity monitoring, and small automation systems.

I ship practical repos: live packet capture with alerts, SHA-256 file baselines, UDP/SSE notification demos, and Discord bots — documented with screenshots and CI where it matters.
